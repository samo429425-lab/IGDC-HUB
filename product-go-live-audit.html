IGDC 실상품 공급 개방 점검

상품 후보·중개수익 대기열에서 시장·검증 증빙·수익 경로·PSOM 승인을 모두 마친 상품을 공개 직전에 다시 확인합니다. 일반 점검은 읽기 전용이며, 실제 사이트 게재는 아래의 별도 최종 확인 절차를 통과한 선택 상품에 대해서만 요청됩니다.

관리자 공통 세션 확인 중

현재 화면의 역할

1. 대기열 승인 완료 후보 읽기상품·시장·증빙·수익·PSOM 배정이 끝난 상품만 표시
2. 공개 직전 감사선택 상품, 판매국·지역, 배정 섹션과 차단 사유 재확인
3. 최종 사이트 게재 요청한 상품을 선택하고 별도 확인 문구를 입력한 경우에만 빌드 요청
4. 빌드 안전 게이트원장·시장·수익·Canonical·국가/IP·스냅샷 조건을 다시 통과해야 반영

개방 점검 후보

한 번에 한 상품만 최종 게재 대상으로 선택합니다. 상품 상세페이지 결제는 외부 판매처에서 처리됩니다.
선택상품현재 단계PSOM 배정판매시장수익 경로차단·확인 사항

최종 사이트 게재 요청

주의: 이 버튼은 일반 저장 버튼이 아닙니다.
선택한 상품의 배정을 공개 요청 상태로 전환하고, 기존 사이트 빌드 파이프라인을 호출합니다. 빌드가 다시 모든 안전 게이트를 통과한 경우에만 사이트에 반영됩니다.
먼저 위 표에서 상품 한 건을 선택하세요.
공개 게이트와 빌드 훅이 준비되고, 실상품 운영 모드에서 후보를 선택해야 활성화됩니다.
