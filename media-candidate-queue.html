미디어 콘텐츠 후보 대기열

산마루/SearchBank가 공개 저장소의 원본 전체 영상을 예비 후보로 수집하고, 관리자 검토·승인 후 공개 스냅샷을 생성하는 미디어 관리 화면입니다. 수집 결과는 자동 공개되지 않으며, 예고편·티저·클립은 제외합니다.

읽기 전용 대기열을 자동 연결하는 중입니다.

공개 원본 영상 수집

Internet Archive의 원본 전체 영상만 검색해 예비 후보로 등록합니다. 예고편·티저·클립·하이라이트는 제외하며, 권리와 재생 상태는 승인 전에 반드시 확인해야 합니다.

미디어 후보 점검 JSON

후보 라이브러리·섹션·권리검토 상태·프론트 승격 차단 상태를 읽기 전용으로 표시합니다. JSON 다운로드 버튼은 이 점검 결과를 그대로 저장합니다.

  

  

    
영상 후보 목록

    
1번 최신 섹션은 자동 노출 대상이라 수동 후보에서 제외합니다. 2~10번 섹션 후보만 표시하며, 검증 대기 후보는 공개되지 않습니다.

    

      
      
    

    
섹션영상연도/권역출처화질권리·상태링크 상태산마루 검색시드

  

  
이 페이지는 미디어 콘텐츠 후보 점검 전용입니다. 상품 후보·중개수익 대기열, 실상품 공급 개방 점검, 리베뉴/PG 엔진을 변경하지 않습니다. 검증 완료 후보만 별도 승격 절차를 통해 `data/media.snapshot.json`으로 이동해야 프론트 오토맵에 표시됩니다.
