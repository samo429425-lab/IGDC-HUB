미디어 콘텐츠 후보 대기열

산마루/SearchBank가 검증할 영상 후보를 프론트 공개 전에 확인하는 읽기 전용 대기열입니다. 이 화면은 `media.snapshot.json`을 수정하지 않고, 후보를 프론트 샘플 슬롯에 자동 반영하지 않으며, 외부 영상 재생·다운로드·결제·수익 기록을 실행하지 않습니다.

관리자 공통 세션을 자동 승계하는 중입니다.

후보 필터

미디어 후보 점검 JSON

후보 라이브러리·섹션·권리검토 상태·프론트 승격 차단 상태를 읽기 전용으로 표시합니다. JSON 다운로드 버튼은 이 점검 결과를 그대로 저장합니다.

  

  

    
영상 후보 목록

    
1번 최신 섹션은 자동 노출 대상이라 수동 후보에서 제외합니다. 2~10번 섹션 후보만 표시하며, `verification_required/pending/candidateOnly/seedContent` 상태는 프론트 승격 대상이 아닙니다.

    
섹션영상연도/권역출처화질권리·상태링크 상태산마루 검색시드

  

  
이 페이지는 미디어 콘텐츠 후보 점검 전용입니다. 상품 후보·중개수익 대기열, 실상품 공급 개방 점검, 리베뉴/PG 엔진을 변경하지 않습니다. 검증 완료 후보만 별도 승격 절차를 통해 `data/media.snapshot.json`으로 이동해야 프론트 오토맵에 표시됩니다.
