웹 공개 원본 후보를 정책·섹션·종합랭킹·실제 화질 기준으로 선별하고, 관리자 검토 후에만 공개 스냅샷으로 승격합니다. 수집만으로는 프런트에 노출되지 않습니다.

콘텐츠 공급사 관리

프로덕션·배급사·스튜디오·권리보유사 등 별도 콘텐츠 공급사를 관리합니다. 넷플릭스·프라임비디오·유튜브 같은 소비자 플랫폼 목록이 아니라, 제휴·계약·직접 협력 가능한 공급사 레지스트리입니다. 공급사 리서치 결과는 후보 상태로만 저장되며, 공급사 영상도 기존 미디어 후보 대기열의 관리자 승인과 SearchBank 정책을 통과하기 전에는 프론트에 노출되지 않습니다.

품질 중심 공개 영상 수집

최신·인기·권리표시 장편과 중국권·동남아권·유럽권·남미권·북미권 자료를 독립 경로로 교차 탐색하고, 2000년 이후 실제 1080p 이상, 섹션별 전체 길이, 최소 비트레이트, 분류 확신도와 실제 원본 응답속도를 함께 검사합니다. 섹션 본선 정원을 채우면 12개 탐색 경로를 한 번 더 확인해 더 좋은 후보를 본선에 우선 배치하고, 남은 우수 후보는 각 섹션별 예비 20개까지만 유지합니다. 새로 수집된 후보는 기존 운영·예비 후보와 분리된 최신 리서치 후보 목록에서 비교·승격합니다. 명백한 포르노·헨타이·불법 신호는 차단하고, 애매한 성인성·권리·분류 신호는 관리자 검토로 격리합니다. 일반 로맨스는 차단하지 않습니다.

운영 후보 · 예비 후보 · 최신 리서치 후보 관리

기존 운영 후보와 새로 리서치된 후보를 분리해 관리합니다. 일반 섹션은 실제 운영 100개 + 예비 20개, 음악·쇼츠는 기존 슬롯 50개 + 예비 20개를 유지합니다. 최신 후보는 별도 목록에서 기존 운영 후보와 품질·인기·최신성·재생 안정성·섹션 적합도를 비교한 뒤 승격합니다. 상태는 보류(보관·복구 가능), 삭제(현재 후보에서 제거·향후 재검색 허용), 영구 제외·차단(일반 재수집 차단)으로 분리합니다.
