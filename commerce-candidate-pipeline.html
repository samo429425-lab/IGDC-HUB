상품 후보·중개수익 비공개 대기열

상품 리서치에서 넘어온 후보를 비공개로 검토·보완하고, 판매시장·검증 증빙·수익 경로·PSOM 배정과 관리자 승인을 완료하는 작업 대기열입니다. 이 화면은 사이트 게재 직전 단계가 아니라 그보다 앞선 심사 단계이며, 상품 공개나 결제를 실행하지 않습니다.

관리자 공통 세션을 확인하는 중입니다.

현재 화면의 역할

1. 후보 확인상품명·이미지·가격·공급업체·추천 섹션 확인
2. 검토·보완시장·배송·반품·지원·검증 증빙과 수익 경로 저장
3. PSOM 승인실제 허브·섹션 배정과 최종 관리자 승인
4. 프론트 매칭·개방 점검선택 상품은 이 화면에서 직접 매칭·해제하고, 전체 섹션 관리는 전용 관리 화면에서 처리
PSOM 배정이 끝난 선택 상품은 아래에서 실상품 프론트 매칭·해제를 직접 실행할 수 있습니다. 여러 상품·여러 섹션·전체 섹션의 배치와 매칭은 18개 섹션 전용 관리 화면을 단일 원장으로 사용합니다.

상품 후보·중개수익 점검 JSON

후보 리서치 결과를 비공개로 관리하며, 관리자 선택 → 판매시장·배송 근거 → 검증 증빙 → 승인 수익 경로 → PSOM 배정 순서가 완료된 후보만 다음 단계의 실상품 공급업체·상품 개방 점검으로 넘깁니다. 선택 상품의 명시적 프론트 매칭·해제 외에는 자동 공개나 결제를 실행하지 않습니다.
