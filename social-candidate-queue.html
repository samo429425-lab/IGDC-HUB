소셜 네트워크 허브 최신 콘텐츠 후보 관제

국가·언어에 맞는 공개 SNS 인플루언서를 선별한 뒤, 계정 자체가 아니라 각 인플루언서가 최근 공개한 영상·게시물을 9개 섹션별로 수집·검토합니다. 운영 채널 주소는 내부 식별과 중복 방지에만 보존합니다. 후보를 확정해도 실제 적용 버튼을 누르기 전까지 기존 샘플 슬롯은 유지하며 외부 플랫폼의 권한을 우회하지 않습니다.

연결 준비 중

전 세계 권역 · 국가 · 접속 국가(IP) 관리 범위

소셜 허브는 주·성 단위로 나누지 않고 국가 단위로 관리합니다. 권역은 국가 목록을 빠르게 찾기 위한 분류이며, 선택한 국가는 후보 수집·최종 100개 정리·실제 프론트 적용에 함께 사용됩니다. 언어는 프론트의 기존 30개 언어 전환 체계를 그대로 사용합니다.
현재 선택한 권역·국가가 관리 작업 범위로 전달됩니다. 향후 관리자 계정에는 같은 국가 범위만 연결하면 됩니다.
국가 목록과 접속 국가를 확인하는 중입니다.

섹션별 공개 SNS 최신 콘텐츠 수집

한 번에 100개를 검색하지 않습니다. 선택한 섹션을 8~10개 단위로 조사·검증·저장합니다. 국가별 선호 언어를 검색어와 배치 기준에 반영하고, 한 인플루언서당 최신 공개 콘텐츠 1건을 후보로 유지합니다. 100개에 도달하면 인기·품질·활동성 중심의 보강 검색을 공개 디렉터리·직접 검색 API·산마루 검색의 세 경로로 나누어 실행하고, 전체 비교 후보에서 상위 100개를 공개 배치 대상으로 정리합니다. 100개 전에 연속 검색에서 신규 후보가 더 이상 나오거나 보강 검색이 소진되면 다음 섹션으로 넘어갑니다. 국가는 소셜 전용 국가 단위이며 주·성은 사용하지 않습니다. 검색 결과 페이지·플랫폼 홈·소셜마루·우측 패널·seed·placeholder는 후보로 반입하지 않습니다.
공개 배치 100개 + 품질 보강수집 전
API 키가 없어도 공개 디렉터리에서 인플루언서를 찾고 YouTube 공개 RSS로 최신 영상을 8~10개씩 수집합니다. 설정된 Google·YouTube·Naver와 SearchBank 결과는 추가 탐색 경로로 함께 사용합니다.

공개 최신 콘텐츠 URL 직접 반입

검색 API가 없거나 제한된 플랫폼도 운영할 수 있는 보조 경로입니다. 위에서 국가와 여기의 섹션을 먼저 선택한 뒤 한 줄에 하나씩 붙여넣으세요. 형식: https://공개주소 | 채널명(선택) | 주제(선택). 영상·게시물 주소는 표시 후보로 유지하고, 확인 가능한 운영 채널·프로필·커뮤니티 주소는 내부 식별자로 함께 보존합니다.
