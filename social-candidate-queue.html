소셜 콘텐츠 후보 대기열

Sanmaru/SearchBank가 넓게 발견한 SNS 후보를 프론트 공개 전에 확인하는 읽기 전용 대기열입니다. 이 화면은 후보 상태 검토, 승인 후보 로테이션 미리보기, 생성용 `social.snapshot.json` 다운로드를 지원합니다. 런타임 정적 파일을 직접 수정하지 않고, 승인 후보가 있는 슬롯만 치환하며, 나머지 샘플 슬롯은 유지합니다. 외부 SNS 호출·광고 우회·로그인 우회·결제·수익 기록은 실행하지 않습니다.

읽기 전용 대기열을 자동 연결하는 중입니다.

후보 필터

소셜 후보 점검 JSON

후보 저장소·섹션별 후보 수·플랫폼별 후보 수·공개 스냅샷 미변경 상태를 읽기 전용으로 표시합니다. JSON 다운로드 버튼은 이 점검 결과를 그대로 저장합니다.

  

  

    
SNS 후보 목록

    
대상은 9개 SNS 섹션입니다. `social-maru`와 `rightPanel`은 제외합니다. seed/placeholder는 원장과 샘플 슬롯에 보존되며, 실콘텐츠 후보 저장소에는 들어가지 않습니다.

    
섹션/플랫폼콘텐츠크리에이터접근/표시점수검증상태외부권한 정책원본 URL검토 액션

  

  
이 페이지는 소셜 콘텐츠 후보 점검·상태 변경·로테이션 미리보기·생성 스냅샷 다운로드 전용입니다. 승인 완료 후보가 없으면 기존 샘플 슬롯은 그대로 유지됩니다. 생성본을 실제 `data/social.snapshot.json` 및 `netlify/functions/data/social.snapshot.json`에 반영하는 작업은 배포 전에 별도 확인 후 진행합니다.
