소셜 콘텐츠 후보 대기열

Sanmaru/SearchBank가 넓게 발견한 SNS 후보를 프론트 공개 전에 섹션별로 수집·검토하는 관리자 대기열입니다. 승인 후보가 있는 슬롯만 치환하고 나머지 샘플 슬롯은 유지합니다. 외부 플랫폼의 광고·로그인·멤버십 권한은 우회하지 않습니다.

읽기 전용 대기열을 자동 연결하는 중입니다.

섹션별 소셜 후보 수집

산마루 공개검색을 실제 실행한 뒤 각 플랫폼의 게시물·영상·공개 채널처럼 원본으로 바로 열리는 주소만 지정 섹션 후보 대기열로 가져옵니다. 검색 결과 페이지·플랫폼 홈·소셜마루·우측 패널·seed·placeholder는 수집하지 않습니다.
수집 전

섹션·플랫폼·상태 검색

소셜 후보 점검 JSON

후보 저장소·섹션별 후보 수·플랫폼별 후보 수·공개 스냅샷 미변경 상태를 읽기 전용으로 표시합니다. JSON 다운로드 버튼은 이 점검 결과를 그대로 저장합니다.
