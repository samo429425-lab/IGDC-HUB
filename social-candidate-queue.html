소셜 네트워크 콘텐츠 운영

이 화면의 주 관리 대상은 콘텐츠입니다. 9개 SNS별 최신 콘텐츠를 수집하고, 현재 후보·새 수집·프론트 적용 예정·예비 교체·보류·차단 상태를 분리해서 관리합니다. 인플루언서 등록부는 콘텐츠 수집을 돕는 보조 관리 영역으로 화면 하단에 분리합니다. 프론트 실제 적용 버튼을 누르기 전에는 기존 프론트 슬롯을 바꾸지 않습니다.

연결 준비 중

전 세계 권역 · 국가 · 접속 국가(IP) 관리 범위

소셜 허브는 주·성 단위로 나누지 않습니다. 국가를 직접 선택하면 해당 국가의 실제 소비 성향을 우선하고, 국가를 선택하지 않으면 접속 IP 국가를 우선합니다. 권역만 선택하면 같은 권역을 우선하며, 전 세계 공통을 직접 선택한 경우에만 글로벌 기준으로 동작합니다. 모든 모드에서 같은 권역과 글로벌 인기 콘텐츠는 보완 후보로 유지하며 국적만으로 후보를 차단하지 않습니다.
선택한 국가·권역 또는 IP 자동 기준이 후보 수집·정리·실제 적용까지 그대로 승계됩니다. 후보는 현지 소비성향 → 같은 권역 → 글로벌 순으로 가중치를 적용합니다.
국가 목록과 접속 국가를 확인하는 중입니다.

AI 전자동 소셜 운영

현재 선택 국가·권역·IP 소비성향을 그대로 승계해 최신 콘텐츠 수집 → 정책·품질 재평가 → 교체 예정 갱신을 순서대로 실행합니다. 기본값은 관리자 검토용 교체 대기열까지만 만들며, 아래 체크를 켠 경우에만 마지막 실제 적용까지 진행합니다.
대기
자동화 범위: 최신 콘텐츠 수집 → 정책·품질 평가 → 공개 100개 + 예비 20개 정리 → 밀려난 콘텐츠 보류 대기 이동. 프론트 실제 적용은 위 체크를 켠 경우에만 마지막 단계에서 실행합니다.

섹션별 공개 SNS 최신 콘텐츠 수집

한 번에 100개를 검색하지 않습니다. 선택한 섹션을 8~10개 단위로 조사·검증·저장합니다. 국가별 선호 언어를 검색어와 배치 기준에 반영하고, 한 인플루언서당 최신 공개 콘텐츠 1건을 후보로 유지합니다. 120개 후보 풀에 도달하면 인기·품질·활동성 중심의 보강 검색을 공개 디렉터리·직접 검색 API·산마루 검색의 세 경로로 나누어 실행하고, 전체 비교 후보에서 상위 100개를 공개 배치 대상으로, 다음 20개를 예비 교체 후보로 정리합니다. 120개 전에 연속 검색에서 신규 후보가 더 이상 나오거나 보강 검색이 소진되면 다음 섹션으로 넘어갑니다. 국가는 소셜 전용 국가 단위이며 주·성은 사용하지 않습니다. 검색 결과 페이지·플랫폼 홈·소셜마루·우측 패널·seed·placeholder는 후보로 반입하지 않습니다.
콘텐츠 후보 120개 = 공개 100 + 예비 20수집 전
SearchBank 실후보 반입은 이미 SearchBank에서 발견된 공개 소셜 후보를 관리자 후보 목록으로 가져오는 자동 입력 경로입니다. 아래의 최신 콘텐츠 후보 반입은 관리자가 직접 공개 URL을 넣는 수동 입력 경로이므로 서로 역할이 다릅니다.

공개 최신 콘텐츠 URL 직접 반입

최신 콘텐츠 후보 반입은 관리자가 직접 확인한 공개 SNS 콘텐츠 URL을 현재 SNS 후보 목록으로 넣는 수동 입력 경로입니다. SearchBank 실후보 반입과는 별개이며, 검색 API가 없거나 제한된 플랫폼에서도 사용할 수 있습니다. 위에서 국가와 여기의 섹션을 먼저 선택한 뒤 한 줄에 하나씩 붙여넣으세요. 형식: https://공개주소 | 채널명(선택) | 주제(선택). 영상·게시물 주소는 표시 후보로 유지하고, 확인 가능한 운영 채널·프로필·커뮤니티 주소는 내부 식별자로 함께 보존합니다.
