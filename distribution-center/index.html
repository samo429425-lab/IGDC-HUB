접속 국가 확인 중

웹 검색은 별도 탭에서 확인합니다. 브랜드 선택 후 상품 목록을 조회하고, 허용된 원본 상품 자료는 수집 도구 또는 공급 자료 파일로 가져올 수 있습니다. 검색 국가 선택은 실제 현지 IP 변경이 아닙니다.

임시 지정은 DB 저장 없이 조회합니다. 영구 저장은 기존 판매자 등록 권한과 DB 정책을 적용합니다. 직접 지정한 주소도 본사 승인 없이 서버 원본 조회를 실행하지 않습니다.
