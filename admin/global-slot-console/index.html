승인 결과 발행

현재 Netlify 정적 Snapshot 발행은 GLOBAL 배치만 반영합니다. 국가별 배치는 원장·권리·정책·승인 기록으로 보존되며, 국가 선택 Front 소비 계약이 연결되기 전에는 전역 카드로 승격하지 않습니다. Netlify 빌드가 끝나면 기존 SearchBank 원본을 보존한 채 전역 승인 결과만 반영됩니다.
