1. 관리자 원장 URL 점검

상품 상세 링크가 /challenge?auth=... 등 접근 제한 페이지로 저장됐는지 확인합니다. 인증 토큰은 화면이나 보고서에 기록하지 않습니다.

점검 전

먼저 읽기 전용 전체 점검을 실행하십시오.

2. 확인된 원본 상세주소만 복구

오염된 접근 제한 URL을 원래 상품 링크로 복원하는 작업입니다. 원래 주소가 내부 기록에 보존돼 있고 같은 판매자·특정 상품번호를 확인한 경우에만 버튼이 활성화됩니다. 상품 보류 상태나 배치 원장은 바꾸지 않습니다.

점검 전

중요한 제한

원래 상품주소가 서버 기록에서 완전히 사라졌다면 긴 인증 토큰을 해독해서 상품번호를 복구할 수 없습니다. 그런 항목은 자동으로 다른 상품을 꽂지 않고 복구 불가로 표시합니다. Cafe24 서버가 여전히 실제 원본 상세주소에 대한 접근을 차단한다면, URL 복구 후에도 일시적인 제한 화면이 뜰 수 있으며 판매자 서버 접근 제한을 우회하지 않습니다.
